# P0-02 — Visual refinement: QA report

> Unofficial redesign concept — Not affiliated with Zenzo.

Run: 2026-10-28 · Chromium (Playwright) against the production build served by `vite preview`.
Reproduce: `npm run build && npm run preview` then `npm run qa`. Raw results: `qa/report.json`.

## What changed since P0-01

| Area | Change |
| --- | --- |
| **VIP** | Rebuilt as three differently composed chapters instead of one pinned image + text list. **I** portrait frame left, copy bottom-aligned right. **II** landscape frame bleeding off the right edge, copy set against it. **III** full-bleed cinematic band with the copy in two columns beneath. Each photo sits inside its own chapter, so image and text can no longer be out of sync (the old scroll-driven image swap is gone). Added a three-item index of jump links. Outline numerals, ruled inclusion lists, a one-time wipe reveal and gentle parallax on each frame, and a hover grade (held-back → full colour). Mobile: edge-to-edge frames, the middle one inset and bleeding right, ruled lists at 16px. Copy and inclusions are unchanged from the venue's published list. |
| **Gallery** | Three-row composition, each row a large frame paired with smaller ones, alternating sides. Only three crop ratios (3:2, 4:5, 1:1). Large frames in full colour, small frames held back until hovered. Removed the dark caption gradient; captions now sit under each frame (number, descriptive title, photographer). Hover affordance is a small square "+" tag. Fixed a mobile bug where the lead frame rendered one column wide. |
| **Hero** | Supporting text brighter and larger on mobile; slightly stronger grade behind the text on small screens (same overlay layers, retuned); primary CTA full width on phones with the secondary link beneath; tighter mobile spacing. Headline, photo and animation unchanged. |
| **Visit** | The location photo and the directions link are now one object: the link is a bone bar fixed to the foot of the photograph, with the address printed on it. The photo's top aligns with the address headline. Enquiries / hours / Lost & Found are ruled rows (Lost & Found no longer a separate bordered box). On mobile the photo follows the headline directly. |
| **About (mobile)** | Edge-to-edge portrait photo; the three published figures become spec-sheet rows instead of three cramped columns. |
| **Global** | Mobile section padding 5.5rem → 4.5rem; Experience pillars tightened on mobile; a shared `ParallaxPicture` component replaces two ad-hoc implementations; logo link `aria-label` removed (axe: label does not match visible text). |

## Known limitations / not verified

- Chromium only; not tested in Safari or Firefox, or on a physical phone.
- axe-core catches roughly a third of accessibility issues; no screen-reader pass was done.
- Hover states and scroll-linked motion are verified by code and reduced-motion state, not by a recorded interaction.
- The portrait crop of the Private Party photo on 320–390px shows the centre of a landscape source; acceptable
  but the first thing to replace once authorised Zenzo photography exists.
